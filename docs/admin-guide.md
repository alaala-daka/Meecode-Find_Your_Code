# 觅码管理台操作说明

## 登录日志

**入口**：左侧菜单「登录日志」（`/admin/login-events`）；菜单徽章显示今日失败登录数（>0 红标）。

**能看什么**：全部 GitHub 登录/登出事件（成功与失败）、时间、login、事件类型、成败、ip_hash（截断展示）。

**能做什么**：按登录名模糊、成败、事件类型、日期范围（UTC 日，含首尾当日）过滤；行内「反查」输入完整 IP 查同 IP 全部行为（每次反查留审计记录）。失败行保留 180 天，成功行永久保留。

**常见操作**：调查异常登录 = 过滤「失败」+ 缩日期；确认某 IP 行为 = 任一行「反查」。

## 全局搜索

**入口**：顶栏搜索框（任意页可用），回车进 `/admin/search?q=`。

**能看什么**：用户（login/简介）、仓库（仓名/标题/简介，走全文索引）、评论（正文，已删除不入搜）三组结果，每组最多 5 条 + 命中计数（超过 1000 显示「1000+」）。

**能做什么**：点「查看全部 →」进对应列表页继续过滤；搜索词 2–50 字，支持中文子串。
